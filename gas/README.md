# Google Apps Script 운영 도구

이 폴더의 `Code.gs`는 Culture-Fit 웹 애플리케이션이 사용할 Google Spreadsheet를 준비하고 운영하기 위한 보조 도구입니다. 검사 웹사이트 자체를 GAS로 실행하는 코드는 아닙니다.

## 설치

1. 검사에 사용할 Google Spreadsheet를 엽니다.
2. `확장 프로그램 > Apps Script`를 선택합니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 전체를 붙여넣습니다.
4. 프로젝트 설정에서 시간대가 `Asia/Seoul`인지 확인합니다.
5. 함수 목록에서 `setupCultureFitWorkbook`을 선택해 한 번 실행합니다.
6. Google 권한 요청을 승인한 뒤 스프레드시트를 새로고침합니다.

이후 상단에 `Culture-Fit 운영` 메뉴가 나타납니다.

## 만들어지는 탭

- `Candidates`: 지원자 등록과 응시 허용 상태
- `Responses`: V1 응답
- `Responses_V2`: 고정 192문항 V2 응답
- `Responses_V2_Bank`: 기본 300문항 은행 V2 응답
- `EventLogs`: 화면 이탈 등 검사 이벤트
- `운영가이드`: 스프레드시트 ID와 주요 운영 설정

응답 탭에는 패키지의 문항 JSON과 같은 순서로 전체 문항 ID 헤더가 생성됩니다.

## 운영 메뉴

- `전체 초기 설정`: 필수 탭, 헤더, 서식, 입력 규칙을 생성합니다.
- `구성 점검`: 필수 탭과 헤더, 시간대, 지원자 중복·누락을 점검합니다.
- `헤더·서식 복구`: 기존 응답 행을 보존하면서 안전한 범위의 설정을 복구합니다.
- `지원자 1명 추가`: 대화상자를 통해 지원자를 등록합니다.
- `선택 지원자 응시 허용/차단`: Candidates에서 선택한 행의 권한을 변경합니다.
- `선택 지원자 재응시 초기화`: 상태와 시작·완료 시각을 초기화합니다. 기존 응답은 삭제하지 않습니다.
- `스프레드시트 ID 보기`: 웹 애플리케이션의 `SHEET_ID` 값을 보여줍니다.

## 주의사항

- 응답이 이미 있는 탭에서 예상 헤더와 실제 헤더가 다르면 스크립트는 자동 덮어쓰지 않고 중단합니다.
- 응답 탭과 EventLogs에는 실수 방지용 경고 보호만 적용합니다. 서비스 계정의 기록을 막지 않기 위해 편집 제한 보호는 적용하지 않습니다.
- 서비스 계정 JSON과 관리자 토큰은 Apps Script나 셀에 입력하지 않습니다. 웹 애플리케이션의 환경 변수에만 보관하세요.
- 서비스 계정의 `client_email`을 스프레드시트 편집자로 공유해야 웹 애플리케이션이 응답을 기록할 수 있습니다.
